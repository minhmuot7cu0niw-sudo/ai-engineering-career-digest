It handles text and images, tool calls, and thinking, and scores 79.2% on SWE-Bench Verified).</p> <div class="snippet-clipboard-content notranslate position-relative overflow-auto" data-snippet-clipboard-copy-content=" ollama run inkling-2-mini"><pre class="notranslate"><code> ollama run inkling-2-mini </code></pre></div> <p>Note: inkling-2-mini is supported on Apple silicon only in this release.
