发生了什么

该版本包含完整变更列表，并将停止发出 active_goal stream event。

你现在做什么

Ollama API 展示模型思考控制信息

发生了什么

v0.34.3-rc1 的 GET /api/show 会展示模型的 thinking controls 及其默认设置。

为什么重要

模型能力和默认思考设置变得更容易通过 API 获取，有助于构建更明确的模型配置与调用逻辑。

你现在做什么

若使用 Ollama API，检查客户端是否读取并展示这些字段，并在调用侧显式记录思考设置。

02.03GitHub Release: QwenLM/qwen-code重要度 3

Qwen Code Desktop 修复会话级 ACP 权限队列问题

发生了什么

该桌面版本包含将 ACP permission queue 限定到 session 的修复。

为什么重要

权限队列的会话隔离关系到多会话开发场景中的操作边界和授权体验。

你现在做什么

升级后测试并行会话下的权限请求，确认一个会话的授权不会影响其他会话。

02.04GitHub Release: QwenLM/qwen-code重要度 2

Qwen Code SDK TypeScript v0.1.13 更新绑定 CLI 版本

发生了什么

为什么重要

SDK 与 CLI 的绑定版本会影响构建可复现性和集成兼容性。

你现在做什么

锁定 SDK 与 CLI 版本，并在 CI 中增加版本核对和回归测试。
