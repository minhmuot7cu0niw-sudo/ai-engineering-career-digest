01.01GitHub Release: QwenLM/qwen-code重要度 5

Qwen Code v0.21.8 恢复 fork PR 实时自动修复

发生了什么

Qwen Code v0.21.8 通过把评审事件桥接到具备凭证的工作流，恢复了来自 fork 的拉取请求的实时自动修复支持。

在测试仓库升级并验证 fork PR 场景，同时检查工作流的最小权限、事件来源校验和密钥暴露边界。

02.02Hacker News重要度 3

发生了什么

Pacific Slate 被介绍为可自托管且不绑定特定模型的多智能体 AI 助手。

为什么重要

自托管和模型无关设计有助于控制数据边界并降低供应商锁定，但也会增加部署与运维责任。

你现在做什么

用一项低风险内部流程做概念验证，记录模型切换成本、数据流向、权限隔离和运维负担。

你现在做什么
