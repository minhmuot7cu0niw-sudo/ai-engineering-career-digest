01

本周最值得试

01.01GitHub API重要度 5

rtk-ai/rtk

发生了什么

面向 AI 编码代理的 CLI 代理工具，通过压缩常见开发命令的输出，减少发送给 LLM 的无效上下文和 token 消耗；以单个 Rust 二进制文件交付且无外部依赖。

为什么重要

与 Codex 和 AI 编码工作流直接相关。它适合用于测试命令、日志和版本控制输出较长的仓库，可具体评估上下文占用、响应聚焦程度及使用成本，而不只是增加新的提示词集合。

你现在做什么

本周先在一个熟悉的小仓库安装并接入一个高输出命令，分别记录原始输出与代理后的输出，再检查关键信息是否完整以及 Codex 完成同一任务时的效果。

01.02GitHub API重要度 4

ActivityWatch/activitywatch

发生了什么

跨平台、可扩展且重视隐私的自动时间追踪工具，用本地活动数据呈现应用和工作时段分布，解决仅凭感觉判断时间投入与专注状态的问题。

为什么重要

能为个人工作流优化提供可量化基线，例如比较 AI 编码、调试、阅读和沟通的实际时间占比，也能帮助识别上下文切换是否抵消了 Codex 带来的效率收益。

你现在做什么

本周安装后连续采集三个正常工作日，只设一个观察目标：统计深度编码时段和高频切换时段，不急于调整全部习惯。

01.03GitHub Trending重要度 4

drawdb-io/drawdb

发生了什么

免费的在线数据库关系图编辑器和 SQL 生成工具，用可视化方式设计 ER 模型，并将结构转成 SQL，降低从需求梳理到数据库原型的沟通和实现成本。

为什么重要

既能提升日常开发效率，也适合作为职业作品集的辅助工具：可以把个人项目的数据模型、关系说明和生成的迁移脚本一起纳入仓库，让架构思路比单纯展示代码更容易被评审。

你现在做什么

选择一个正在做或计划放入作品集的项目，画出核心 5 至 8 张表及关系，导出对应 SQL，并在 README 中加入模型图和关键设计取舍。
