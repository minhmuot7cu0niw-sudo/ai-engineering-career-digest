01.02GitHub Release: ollama/ollama重要度 5

Ollama v0.32.10 候选版调整重复惩罚并优化 NVFP4 预填充

发生了什么

未显式设置 repeat_penalty 的模型现在默认使用 1.0，而非 1.1，以匹配其他引擎并加快推测解码；同时提升 NVFP4 MLX 模型的预填充速度。

为什么重要

默认采样参数变化可能影响既有模型的输出重复情况，而预填充优化会直接影响本地推理的首 token 延迟和吞吐表现。该版本仍是 RC。

你现在做什么

先在测试环境对固定提示集做升级前后对比，记录重复率、首 token 延迟和吞吐；若旧模型出现重复，按模型显式设置 repeat_penalty。

01.03GitHub Release: anthropics/claude-code重要度 4

Claude Code v2.1.229 增强远程会话恢复与自托管 Hook

发生了什么

该版本记录了使用 claude remote-control --continue 恢复最近远程会话的方法，并为自托管 runner 会话加入服务端下发的 Claude Code Hook 支持，同时增加 SSE keepalive。

为什么重要

这些变化改善了远程编码任务的连续性，也让自托管执行环境更接近托管环境的 Hook 能力。

你现在做什么

使用远程控制或自托管 runner 的团队应验证断线恢复、Hook 权限边界和长连接稳定性，再决定是否更新生产工作流。

工程实践

02.01Hacker News重要度 5

用 Prism Eval 为智能体编排器建立命令行单元测试

发生了什么

Prism Eval 是一个面向智能体 AI 编排器的开源命令行单元测试项目。

为什么重要

代理系统需要可重复的回归验证，才能发现提示词、模型或编排逻辑变更造成的行为退化。

你现在做什么

选择一个现有代理流程，先覆盖成功路径、工具调用失败和异常输出三类案例，并将测试命令接入 CI。

02.02Hacker News重要度 4

Context Bombs 探索阻止 AI 攻击者的方法

发生了什么

文章介绍了名为 Context Bombs 的方法，用于阻止 AI 攻击者。

为什么重要

随着自动化攻击代理出现，防御机制不仅要面对传统脚本，也需要考虑模型上下文和代理行为。

你现在做什么

在隔离环境阅读并复现实验思路，评估其误伤、绕过方式及 token 成本；未经验证不要直接部署到生产入口。

02.03GitHub Release: anomalyco/opencode重要度 4

OpenCode 修复会话压缩与模型配置问题

发生了什么

v1.18.17 让会话压缩保留完整的近期轮次，并为较小模型生成更清晰的摘要；同时加入 MERGE Gateway 推理变体。

为什么重要

上下文压缩质量会影响长会话中的需求保持和代码修改一致性，尤其会影响上下文能力较弱的小模型。

你现在做什么

用包含多轮需求变更的真实任务回放新旧版本，检查压缩后是否保留最新约束、未完成事项和关键文件信息。

02.04Hacker News重要度 3

llms.txt 在 83 个网站上的实际抓取次数有限

发生了什么

该实验在 83 个网站部署 llms.txt，12 周内观察到 OpenAI 爬虫读取 7 次。

为什么重要

这组结果表明，至少在该实验范围和观察期内，不能把 llms.txt 当作稳定触达 AI 爬虫的唯一机制。

你现在做什么

将 llms.txt 视为补充措施，同时保留 robots.txt、访问日志监控和服务端访问控制，并用自己的日志验证各爬虫行为。
