## 工程实践

### [Codex 0.147.0 增加可移植 Agent Plugins 与多来源插件搜索](https://github.com/openai/codex/releases/tag/rust-v0.147.0)

- 来源：GitHub Release: openai/codex
- 摘要：Codex 0.147.0 支持安装可移植的 Agent Plugins，并可搜索本地、个人、工作区和远程插件目录。
- 为什么重要：插件分发和发现能力会降低智能体工具复用成本，但也扩大供应链、权限和版本兼容风险。
- 下一步：在升级前建立插件白名单，固定关键插件版本，并审查插件所需的文件、网络和命令执行权限。

### [Qwen Code 0.21.7 移除 Goals 的 50 轮限制](https://github.com/QwenLM/qwen-code/releases/tag/v0.21.7)

- 来源：GitHub Release: QwenLM/qwen-code
- 摘要：Qwen Code 0.21.7 移除了 Goals 的 50 轮上限，使任务可以超过此前边界继续和恢复。
- 为什么重要：长任务续跑能力适合大型改造和复杂排障，但会增加成本失控、上下文漂移和重复操作的概率。
- 下一步：评估新版时为长任务设置独立预算、阶段检查点和停止条件，并测试中断恢复后是否会重复修改或执行命令。

### [Tracely 将智能体生产故障转化为 CI 回归测试](https://tracely-studio.xyz/)

- 来源：Hacker News
- 摘要：Tracely 的定位是把 AI 智能体在生产环境中的失败转换为 CI 回归测试。
- 为什么重要：智能体输出具有不确定性，只有将真实故障沉淀为持续测试样本，修复才不容易在模型、提示词或工具升级后失效。
- 下一步：从近期生产故障中选取 5 个代表案例，脱敏后固化输入、期望行为和禁止行为，并加入每次发布前的回归流程。

### [Selvedge 记录智能体已经拒绝的候选项](https://github.com/masondelan/selvedge)

- 来源：Hacker News
- 摘要：Selvedge 是一个追加写日志，用于保存 AI 智能体已经拒绝过的内容或选项。
- 为什么重要：保留拒绝历史可以减少重复探索，并为智能体决策审计、调试和恢复提供上下文。
- 下一步：在智能体状态中增加只追加的决策记录，至少保存候选项、拒绝原因、时间和任务标识，同时设置脱敏与保留期限。
