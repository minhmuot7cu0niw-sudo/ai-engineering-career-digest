### [AI agents that inherit the user's permissions, not API keys](https://blog.cloudflare.com/how-we-use-ai-with-cloudflare-os/)

- 来源：Hacker News
- 摘要：Cloudflare 介绍让 AI Agent 继承用户权限，而不是直接持有 API 密钥的方案。

- 下一步：在下一个 Agent 原型中用用户身份委托替代共享密钥，并验证权限撤销、会话过期、资源级授权和审计归属。
